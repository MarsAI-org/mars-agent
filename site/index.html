Mars

A coding agent with the IDE wired in.

Install

Install Mars quickly via the official install scripts:

macOS & Linux:

curl -fsSL https://getmars.eu.cc/install | sh

Windows (PowerShell):

irm https://getmars.eu.cc/install.ps1 | iex

Or download prebuilt release binaries directly from GitHub Releases:

https://github.com/MarsAI-org/mars-agent/releases

Source Code & Documentation
